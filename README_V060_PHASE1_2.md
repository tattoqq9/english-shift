# English Shift v0.6.0 Phase 1.2 — Shifts Screen

This patch replaces the abstract Course screen with the approved Shifts stage-select design.

Visible primary navigation:

```text
Today | Shifts | Review | More
```

Shifts now has one job:

> choose / locate a Shift in the 48-Shift main route.

Top level shows:
- progress
- current store image
- direct Continue button
- eight-store vertical route

Tapping a store opens its existing six-Shift chapter screen.

This patch does not change:
- learning content
- scoring
- Mastery
- saved-progress schemas
- character assignments
- Today direct-launch behavior

SELECT/BUILD pairing is intentionally not shown at this top level until Phase 2 implements paired progression.
